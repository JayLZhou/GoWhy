# GoWhy 的理论部分（论文方法章节底稿）

2026-10-08。记号和命题，配实测对照。证明写到能直接改写进论文的程度。

## 1. 模型

- **Agent 是"提示 → 回复"的随机策略**：第 k 步，harness 把任务、历史和当前观察拼成提示 p_k（AgentDebug 的 harness 是无状态的，每步一条完整提示），策略按温度 T 采样回复 r_k ~ π(· | p_k)，解析出动作 a_k，环境确定性地给出下一观察。所以一局游戏是一条马尔可夫链，状态就是提示，**下一步动作的分布只由当前提示决定**。
- **轨迹库**：N 局游戏 g_1..g_N，每局一条用基础策略 π 跑出的轨迹 τ_i 和结局 Y_i ∈ {0,1}。
- **改动 C = (谓词 φ, 效果 e, 作用域)**：在 φ(当前步属性, 即将采取的回复) 为真的步上，把 π 替换成 e 定义的新采样过程（拒绝重抽、反馈后重答、换模型、固定动作），作用域 FIRST 只在第一次触发时生效，ALL 每次触发都生效。改后策略记 π^C。
- **查询目标**：Δ(C) = (1/N) Σ_i ( E_{π^C}[Y | g_i] − E_π[Y | g_i] )，即"在这批游戏上部署 C 后，成功率变化多少"。

## 2. 分叉重放估计量

对第 i 局，令 k_i 为 τ_i 上第一个使 φ 为真的步（找不到则 a_i = 0，否则 a_i = 1）。从 τ_i 的前 k_i 步出发，在第 k_i 步用**记录里的那个回复**作为 π^C 的第一次采样，施加效果 e，然后按 π^C 继续到结束，独立重复 n 次，得 V̂_i（n 次的胜率）。

  D_i = a_i ( V̂_i − Y_i ),  Δ̂ = (1/N) Σ_i D_i,  SE = sd(D) / √N.

**命题 1（无偏）。** E[Δ̂] = Δ(C)。

证明要点：对固定游戏 g，把 π 和 π^C 耦合在同一组随机数上。在第一次触发之前，π^C 和 π 的每一步采样分布完全相同（触发条件不成立时 π^C 就是 π），所以前缀 τ_{<k} 在两种策略下同分布，"在第 k 步首次触发"的事件也同概率。在首次触发的那一步，π^C 的第一次采样就是 π 的采样，记录里的回复正是这样一个样本；之后按 π^C 继续，所以 V̂_i 在给定前缀下是 E_{π^C}[Y | τ_{≤k}] 的无偏估计。没触发的局（a_i = 0），整条轨迹在 π^C 下与在 π 下相同，结局不变，差为 0。对前缀分布取期望，E[a_i V̂_i + (1 − a_i) Y_i] = E_{π^C}[Y | g_i]，而 E[Y_i] = E_π[Y | g_i]。∎

推论：未受影响的局**不需要任何重放**，成本只花在受影响局的后缀上。

**注意（选择偏差）**：命题 1 要求 φ 和 C 与 τ_i 的结局无关地事先给定。若 C 是看着同一批 Y_i 挑出来的（挖掘、HOWTO 选最大），Δ̂ 有正偏差（赢家诅咒、回归均值）。我们的协议：在 A 半挖候选，在 B 半估计；对选中的 C 用与选拔不重叠的重放认证；最后在没见过的游戏上 A/B。实测：未认证的"决定性步"15 个里 12 个是假的；A/B 划分与重复运行的挑选共用同一个哈希时，效果虚高约 3 点（PLAN.md 第 9 步）。

## 3. 方差分解与最优重放次数

记 V_i = E_{π^C}[Y | τ_{i,≤k_i}]（给定前缀的真实续跑胜率）。

  Var(D_i) = Var( a_i (V_i − Y_i) ) + E[ a_i V_i (1 − V_i) ] / n  =:  A + B / n.

第一项 A 是"局与局之间"的部分（前缀和记录结局的随机性），不随 n 减小；第二项 B/n 是续跑本身的伯努利噪声。

**命题 2（每局一次最省）。** 设每次续跑的期望成本为 c（token 或调用数），总成本 C(n) = n c Σ_i a_i。则精度与成本的乘积

  SE² · C(n) ∝ (A + B/n) · n = A n + B

关于 n 单调递增，在 n = 1 取最小。更一般地，若只对受影响局的随机子集（概率 q）重放并用 1/q 加权（Horvitz–Thompson），乘积为 (M/q − Δ²) q = M − Δ² q，M = E[a (V̂ − Y)²]，关于 q 单调递减，在 q = 1 取最小。所以**最省的设计是：每个受影响的局恰好重放一次**。

这同时解释了 CV-index 的失败（README 中 T1 不通过）：只物化部分单元格再按 1/q 放大，正是 q < 1 的设计，方差按 1/q 放大，换什么价值模型都压不下来。

**实测对照**（PLAN.md G1）：用 n = 8 估出 A、B，预测 n = 1、2、4 的 SE。

| 模型 | A | B | 预测 SE（n = 1/2/4） | 实测 SE |
| --- | --- | --- | --- | --- |
| Qwen2.5-7B，影响 84% | 0.0563 | 0.0686 | 2.04 / 1.74 / 1.56 | 2.08 / 1.76 / 1.58 |
| Qwen3-8B，影响 22% | 0.0246 | 0.0151 | 1.15 / 1.03 / 0.97 | 1.16 / 1.07 / 0.98 |

## 4. 与重新部署比较

从头部署（A/B）的配对差 D_i^dep = Ȳ_i^{C} − Y_i，每局都要从头跑，且未受影响的局也贡献方差（两次独立运行结局不同）：

  Var(D^dep) ≈ Σ 每局两次独立运行之差的方差 ≈ 2 p (1 − p)（p 为基线成功率附近）。

而分叉重放对未受影响的局方差为 0、成本为 0，对受影响的局只付后缀成本。效率比（同等 SE 所需成本之比）

  [Var(D^dep) · c_full] / [ (A + B) · c_suffix · frac_affected ].

实测（达到 ±1 点所需 token）：Qwen3 4M 对 103M（约 26 倍），Qwen2.5 48M 对 103M（约 2 倍）。影响面越小、分叉越晚，优势越大；影响面接近全体且分叉很早时，优势降到约 2 倍，但不会比部署差（因为 A ≤ Var(D^dep) 成立当且仅当 ……待证，实测成立）。

## 5. 公共随机数（候选之间的比较）

给每次采样一个只依赖（游戏、重放编号、步、步内第几次采样）的种子，与改动无关。两个改动 C_1、C_2 在同一局同一重放编号下用同一串种子：在两者历史相同的步上，采样结果相同（vLLM 批内数值差异会偶尔打破，实测动作一致率 0.97，不固定种子时 0.81），历史分开后各自独立。于是 Cov(D_i(C_1), D_i(C_2)) > 0，差 Δ̂(C_1) − Δ̂(C_2) 的方差小于独立采样时，HOWTO 的排序更准。效果大小待 G2 实测。

只有同一族候选（同谓词、不同效果强度）在分叉后还有共同历史；不同谓词的候选分叉点不同，计算共享只有约 15%（G1 第 2 项不通过），所以公共随机数的收益在"比较更准"，不在"算得更少"。

# v2 理论（2026-10-09）：格上的 how-to、剪枝、好臂认证、预算分配

## 7. 记号

- 原子条件集合 𝒜（|𝒜| = a），谓词 φ ⊆ 𝒜 表示原子的合取，|φ| ≤ k；F(φ) = 记录轨迹上存在某一步使 φ 中所有原子同时成立的局。
- 效果集合 ℰ。候选 C = (φ, e)。Δ(C) 如第 1 节。
- 每局的"反事实增益" g_i(C) = a_i (V_i(C) − Y_i) ∈ [−1, 1]，Δ(C) = (1/N) Σ_{i∈F(φ)} g_i(C)。

## 8. 格上 how-to 的困难性

**命题 6（NP 难）**：即使每局的增益 g_i(C) 全部已知（不需要任何重放），且每局只有一步，"在 |φ| ≤ k 的合取中找使 Σ_{i∈F(φ)} g_i 最大的 φ"也是 NP 难的。

证明思路：每局一步时，F(φ) = ∩_{α∈φ} S_α，其中 S_α 是原子 α 成立的局。取 g_i = 1 对所有局，并要求恰好 k 个原子，问题就是"最大 k 子集交"（从一族集合中选 k 个使交集最大），已知 NP 难。允许 |φ| ≤ k 时，给一部分局赋负增益即可阻止"选更少原子"的平凡解，归约到带符号权重的单项式最大一致问题（不可知学习单项式），同样 NP 难。（两个已知结论的出处投稿前需核对。）

推论：how-to 的困难有两层，组合搜索本身难，而每个候选的增益还要花重放去估。所以需要可靠的界来剪枝，再用老虎机分配重放。

## 9. 可靠剪枝

**命题 7（反单调上界）**：对任意效果 e，

    −|F(φ) ∩ 成功局| / N  ≤  Δ(φ, e)  ≤  |F(φ) ∩ 失败局| / N =: UB(φ)，

且 φ ⊆ φ′ ⇒ F(φ′) ⊆ F(φ) ⇒ UB(φ′) ≤ UB(φ)。所以若已有某个候选的下界 LB*（以 1 − δ′ 成立）满足 UB(φ) < LB*，则 φ 及其所有细化、所有效果都不可能比该候选好，可以剪掉，且剪枝本身不引入任何误差（界是确定的，只用日志）。

证明：增益 g_i ∈ [−Y_i, 1 − Y_i]，未受影响局为 0；交集单调。∎

## 10. 好臂识别与独立认证

**问题 3（好臂识别）**：给定阈值 τ、置信度 δ、预算 B，返回 C 使 P(Δ(C) < τ) ≤ δ；若在预算内无法认证则返回"未认证"及当前最佳估计。

**协议**：搜索阶段可以用任意自适应规则（连续减半、上界顺序、LUCB……）选出至多 m 个候选；认证阶段对每个候选用与搜索独立的新种子，把它覆盖的局各重放一次，得到部署口径估计 Δ̂ 与 SE，计算单侧下界 LCB = Δ̂ − z_{1−δ/m} SE。第一个 LCB ≥ τ 的候选被返回。

**命题 8（认证正确性）**：上述协议满足 P(返回的 C 有 Δ(C) < τ) ≤ δ（渐近于 CLT；用 Hoeffding–Serfling 界代替 z 时为有限样本保证）。

证明：给定搜索阶段的全部数据，认证用的重放与之独立（新种子），所以每次认证的 LCB 对被认证的候选是有效的单侧置信界（定理 1 给出无偏性）。至多 m 次认证，联合界给出 δ。∎

要点：联合界只覆盖 m 次认证，不覆盖格上的几千个候选；这正是最优臂识别在这个规模下停不下来、而好臂识别可以的原因（实测：Hoeffding 或 Bernstein 界的 LUCB 在 3000 次重放后第一名下界仍为 −0.09，而单独认证的下界为 +0.004，见 PLAN.md）。

## 11. 搜索阶段：带范围的连续减半

每个候选的单次拉臂结果 x = V̂ − Y ∈ [−1, 1]，其均值乘以 w = |F|/N 即 Δ。候选的有效范围由命题 7 给出，宽度 ≤ w。

**命题 9（连续减半的固定预算误差，改写自 Karnin 等 2013）**：对 M 个候选按每轮保留 1/η 进行 ⌈log_η M⌉ 轮，总预算 B，则漏掉最优候选的概率不超过

    log_η M · exp( − B / (c · H · log_η M) )，  H = max_j  j · w_(j)² / gap_(j)²

其中 gap_(j) 是第 j 好的候选与最优的差，w_(j) 是其覆盖比例。与标准结论相比多出的 w² 因子来自"候选只影响一部分局"：覆盖窄的候选噪声小，需要的拉臂少；有限总体（每个候选至多 |F| 次不放回抽样）进一步把每个候选的需求封顶在 |F|。（需写出完整证明。）

## 12. 预算分配（ARP）回顾

定理 2（DESIGN_V2.md）：在总代价预算下，使方差最小的重放概率为 q_i ∝ √(r_i / c_i)，方差 × 代价的下界为 (Σ √(r_i c_i))² / N²。"每个受影响局都重放一次"仅在 r_i / c_i 处处相同时最优。实测：已知 r_i 的理想分配相对均匀抽样约 2.7 倍，可实现的版本 1.2–1.7 倍，瓶颈在续跑值预测。

# v3：严格的界（2026-10-10）

本节四个结果都给完整证明，并与实测数据对照。记号同前：任务 g、记录前缀与结局 (τ, Y)、改动 C、每局差 D = a(V̂ − Y) ∈ [−1, 1]。

## 14. 总体认证与分布偏移下的迁移

**设定**：库里的 N 个任务独立同分布于任务分布 𝒟；每个任务的记录轨迹由 π 生成；认证重放在给定前缀下相互独立。定义总体效果

    Δ_𝒟(C) = E_{g∼𝒟} [ E_{π^C}[Y | g] − E_π[Y | g] ]。

**定理 A（总体认证）**：D_1, …, D_N 独立同分布、取值于 [−1, 1]、均值为 Δ_𝒟(C)。因此任何对 [−1, 1] 上独立同分布变量均值有效的 (1 − α) 单侧下界（例如下注式下界）都是 Δ_𝒟(C) 的有效下界：P(Δ_𝒟(C) ≥ LCB) ≥ 1 − α。

证明：不同任务的抽取、记录与重放相互独立，所以 D_i 独立同分布；由定理 1（对固定任务的无偏性）和全期望，E[D_i] = E_g[Δ(C; g)] = Δ_𝒟(C)。∎

含义：认证保证的不是"在库里这些任务上"，而是"在与库同分布的新任务上"。这正是 ALFWorld 评估集（与训练游戏同分布的新游戏）复现了认证效果的原因。

**推论 A1（偏移）**：设每个任务的效果 δ(g) = E_{π^C}[Y|g] − E_π[Y|g] ∈ [−1, 1]。对任意新分布 𝒟′，

    Δ_𝒟′ ≥ Δ_𝒟 − (sup δ − inf δ) · TV(𝒟, 𝒟′) ≥ Δ_𝒟 − 2 · TV(𝒟, 𝒟′)。

证明：|∫ δ d(𝒟 − 𝒟′)| ≤ (sup δ − inf δ) · TV(𝒟, 𝒟′)，对取值在长度为 L 的区间上的函数成立（Hahn 分解）。∎

**推论 A2（按任务类型分层的迁移）**：若 𝒟 与 𝒟′ 只在任务类型的比例上不同（类型内分布相同），对每个类型 t 分别认证 LCB_t（各取 α / T），则对任意类型比例 w′，Σ_t w′_t LCB_t 以至少 1 − α 的概率是 Δ_𝒟′ 的下界。

证明：Δ_𝒟′ = Σ_t w′_t Δ_t，联合界。∎

ScienceWorld 的测试变体与训练变体是**类型内**的偏移（同一任务类型、不同物体与设置），推论 A2 不覆盖，推论 A1 只给出依赖 TV 的保证；这与实测"训练变体上认证 +7.0、测试变体上 +1.2（区间跨 0）"一致：认证不自动迁移到类型内偏移的任务，需要在目标分布上确认。

## 15. Lattice-SH 的固定预算误差界（完整证明）

**设定**：臂 j 对应候选 C_j，覆盖集合 F_j，覆盖比例 w_j = |F_j| / N。对库取条件，第 i 局在 C_j 下的"真增益" h_i = V_i(C_j) − Y_i ∈ [−1, 1] 固定；拉一次臂 = 从 F_j 不放回地均匀抽一局 I 并重放一次，得 x = h_I + ε，其中 ε 给定 I 时均值为 0、取值在长度为 1 的区间内（V̂ ∈ {0, 1} 或 [0, 1]）且相互独立。臂的目标值 μ_j = w_j · m_j，m_j = |F_j|⁻¹ Σ_{i∈F_j} h_i（即库条件下的 Δ）。最优臂记为 1，差距 Δ_j = μ_1 − μ_j > 0。

**引理 B1（单臂集中）**：t 次拉臂的均值 x̄ 满足 P(x̄ − m ≥ u) ≤ exp(−2tu²/5)，下尾同理。

证明：对 λ > 0，E exp(λ Σ_s (x_s − m)) = E[ exp(λ Σ_s (h_{I_s} − m)) · Π_s E[exp(λ ε_s) | I] ]。由 Hoeffding 引理（区间长度 1），每个因子 ≤ exp(λ²/8)。不放回抽样的和的 mgf 不超过有放回抽样的 mgf（Hoeffding 1963，定理 4，凸函数控制），而有放回时每项取值在长度 2 的区间，故 ≤ exp(tλ² · 4/8)。合起来 ≤ exp(5tλ²/8)。Chernoff：P ≤ exp(−λtu + 5tλ²/8)，取 λ = 4u/5 得 exp(−2tu²/5)。∎

**引理 B2（两臂比较）**：两臂各拉至少 t 次时，P(μ̂_j ≥ μ̂_1) ≤ 2 exp(−t Δ_j² / (10 w̃_j²))，w̃_j = max(w_1, w_j)。

证明：μ̂_j ≥ μ̂_1 蕴含 w_j(x̄_j − m_j) ≥ Δ_j/2 或 w_1(x̄_1 − m_1) ≤ −Δ_j/2。对两者分别用引理 B1（u = Δ_j/(2w)），并用 w ≤ w̃_j。（两臂可共享种子，联合界不需要独立性。）∎

**定理 B（Lattice-SH）**：η 元减半，R = ⌈log_η M⌉ 轮，每轮预算 B/R 平均分给当轮存活的 |S_r| = M/η^r 个臂（t_r = B/(R|S_r|)，忽略取整）。定义难度 d_j = Δ_j / w̃_j，按升序排为 d_(1) ≤ d_(2) ≤ …，复杂度

    H_w = max_i  i / d_(i)² = max_i  i · w̃_(i)² / Δ_(i)²。

则最优臂在某一轮被淘汰的概率不超过

    4ηR · exp( − B / (20 η R H_w) )。

证明：第 r 轮最优臂被淘汰，当且仅当 S_r 中至少 |S_r|/η 个臂的经验均值不低于它。令 i_r = |S_r|/(2η)，S_r′ 为 S_r 去掉最优臂和 S_r 中难度最小的 i_r 个臂。若最优臂被淘汰，S_r′ 中至少 |S_r|/η − i_r = |S_r|/(2η) 个臂胜过它。S_r′ 中每个臂的难度不小于 S_r 内第 i_r + 1 小的难度，故不小于全局第 i_r 小的 d_(i_r)。由引理 B2 和 Markov 不等式，

    P(淘汰) ≤ (2η / |S_r|) · |S_r′| · 2 exp(−t_r d_(i_r)²/10) ≤ 4η exp(−t_r d_(i_r)²/10)。

而 t_r d_(i_r)² = B d_(i_r)² / (R · 2η i_r) ≥ B / (2ηR H_w)（由 H_w 的定义，i_r / d_(i_r)² ≤ H_w）。对 R 轮取联合界即得。∎

**与标准结论的比较**：标准最优臂识别的复杂度是 H = max_i i/Δ_(i)²（Karnin 等 2013）。这里多出因子 w̃²：覆盖窄的候选（w 小）方差小、难度低；覆盖宽的候选（w 接近 1）回到标准情形。这解释了实测现象：按上界排序先评估 w 接近 1 的宽谓词，它们的增益又小，难度最大，预算很快耗尽。

**定理 B′（认证后的成功概率）**：若最优臂 Δ_1 ≥ τ + γ，在定理 B 的事件之外再对它做认证（新种子，N 个任务，SE 由 σ_1 / √N 给出），用 CLT 下界时认证成功的概率至少

    1 − 4ηR exp(−B/(20ηR H_w)) − Φ( z_{1−δ/m} − γ√N / σ_1 )。

证明：最优臂进入认证集的概率由定理 B 控制；认证成功的概率是标准的单侧检验功效。∎

## 16. ARP 的最优性：达到 Godambe–Joshi 下界

**设定（超总体模型）**：给定库，第 i 个受影响局的重放增益 x_i = V̂_i − Y_i 满足 E[x_i] = μ_i、Var(x_i) = σ_i²，各局独立；设计以概率 π_i 决定是否重放第 i 局，代价 c_i。

**定理 C**：对任何设计无偏的估计量 T̂（对每个固定的 x 都满足 E_p[T̂] = Σ_i x_i），其预期方差 E_ξ Var_p(T̂) ≥ Σ_i σ_i² (1/π_i − 1)（Godambe 与 Joshi 1965）。在 Σ_i π_i c_i ≤ B 下，下界关于 π 的最小值在 π_i ∝ σ_i / √c_i（截断于 1）处取得，等于 (Σ_i σ_i √c_i)² / B − Σ_i σ_i²。以 μ_i 为预测的双重稳健估计量 T̂ = Σ_i [μ_i + (S_i/π_i)(x_i − μ_i)] 在该 π 下达到下界。

证明：下界为 Godambe–Joshi 定理。最小化 Σ σ_i²/π_i 受 Σ π_i c_i ≤ B：拉格朗日条件 σ_i²/π_i² = λ c_i 给出 π_i ∝ σ_i/√c_i；代回由 Cauchy–Schwarz 得最小值。双重稳健估计量的方差为 Σ_i (1/π_i − 1) E(x_i − μ_i)²，当 μ_i 等于真实均值时等于 Σ σ_i²(1/π_i − 1)，即下界。∎

含义：ARP（r_i = σ_i²、μ_i 为预测）在"预测准确"的极限下是**所有**设计无偏估计量中最优的，不只是在 Horvitz–Thompson 类中；实测 1.2–1.7 倍与理想 2.7 倍之间的差距完全来自 μ_i、σ_i 的预测误差。

## 17. 认证所需样本量（功效界）

**定理 D**：D_i 独立同分布、均值 Δ、方差 σ²。（a）CLT 认证（下界 Δ̂ − z_{1−δ/m} σ̂/√N）以至少 1 − β 的渐近概率成功，若

    N ≥ ( (z_{1−δ/m} + z_{1−β}) σ / (Δ − τ) )²；

（b）用经验 Bernstein 下界（Maurer 与 Pontil 2009，区间长度 2）时，有限样本下充分条件为

    Δ − τ ≥ 2 √( 2σ² log(4m/(δβ)) / N ) + 28 log(4m/(δβ)) / (3(N − 1))。

证明：（a）Δ̂ − z σ/√N ≥ τ 等价于 (Δ̂ − Δ)/(σ/√N) ≥ z − (Δ − τ)√N/σ，后者 ≤ −z_{1−β} 时由 CLT 概率至少 1 − β。（b）经验 Bernstein 界给出以 1 − δ/m 成立的下界宽度 √(2σ̂² log(2m/δ)/N) + 7·2 log(2m/δ)/(3(N−1))；再用 Bernstein 界控制 Δ̂ 以 1 − β/2 不低于 Δ − √(2σ² log(2/β)/N) − 2·2 log(2/β)/(3N)，并控制 σ̂ ≤ σ + √(…)，合并常数得到所述充分条件（常数未做优化）。∎

**对照实测**：ALFWorld 修复 σ ≈ 0.405、Δ ≈ 0.074、δ/m = 0.033：80% 功效需要 N ≥ ((1.83 + 0.84)·0.405/0.074)² ≈ 213 个任务；B 半只有 148 个，渐近功效约 65%，与"CLT 下界 +1.3 刚刚通过、有限样本下注界 −1.0 不通过"一致。ScienceWorld 修复 σ ≈ 0.336、Δ ≈ 0.070：80% 功效需要约 165 个任务，B 半 153 个，渐近功效约 77%，有限样本的下注界也勉强通过（+0.1）。

## 19. 下界：覆盖率平方是问题本身的难度

**设定**：同 §15。对库取条件，臂 j 的一次拉臂从 F_j 中均匀抽一局 i，返回 x = V̂ − Y_i，其中 V̂ ∼ Bernoulli(V_i(C_j))。称一个算法在实例类 𝓘 上是 δ-正确的，若它在 𝓘 的每个实例上都以至少 1 − δ 的概率返回最优臂。设 𝓘_v 为所有续跑值满足 V_i(C_j) ∈ [v, 1 − v]（0 < v ≤ 1/4）的实例。

**定理 E（固定置信下界）**：在 𝓘_v 上，任何 δ-正确的算法（δ ≤ 0.15）对每个次优臂 j 满足

    E[N_j] ≥ v · w_j² · log(1 / (2.4 δ)) / (4 Δ_j²)，    当 Δ_j / w_j ≤ v/2，

其中 N_j 是臂 j 被拉的次数；对最优臂（当 Δ_2/w_1 ≤ v/2），E[N_1] ≥ v · w_1² · log(1/(2.4δ)) / (4 Δ_2²)（Δ_2 为最小差距）。因此总拉臂数

    E[T] ≥ (v/4) · log(1/(2.4δ)) · ( w_1²/Δ_2² + Σ_{j≥2} w_j²/Δ_j² )。

证明：用变换测度引理（Kaufmann、Cappé 与 Garivier 2016，引理 1）：对任意两个实例 ν、ν′，若算法在 ν 上以 ≥ 1 − δ 返回臂 1、在 ν′ 上以 ≥ 1 − δ 返回别的臂，则 Σ_k E_ν[N_k] KL(ν_k, ν′_k) ≥ kl(δ, 1 − δ) ≥ log(1/(2.4δ))。对次优臂 j，构造 ν′：只把 F_j 中每一局的续跑值整体提高 s = (Δ_j + ε)/w_j（Δ_j/w_j ≤ v/2 时，对足够小的 ε 有 s ≤ v/2，于是 V_i + s ∈ [v, 1 − v/2]），其他臂不变，于是在 ν′ 中臂 j 的均值超过臂 1。两实例只在臂 j 上不同；臂 j 的一次拉臂先均匀抽局（两实例相同），再抽 Bernoulli，故每次拉臂的 KL 不超过 max_i kl(V_i, V_i + s)。由 χ² 上界 kl(p, q) ≤ (p − q)²/(q(1 − q))，而 q = V_i + s ∈ [v, 1 − v/2] 时 q(1 − q) ≥ (v/2)(1 − v/2) ≥ v/4（v ≤ 1/2），得每次拉臂的 KL ≤ 4s²/v。代入得 E[N_j] · 4s²/v ≥ log(1/(2.4δ))，令 ε → 0 即得。对最优臂，构造把 F_1 的续跑值整体降低 (Δ_2 + ε)/w_1 的实例（q ∈ [v/2, 1 − v]，同样 q(1 − q) ≥ v/4），同理。求和得 E[T] 的界。∎

**与上界（定理 B）的比较**：上界的复杂度 H_w = max_i i · w̃_(i)²/Δ_(i)² 与求和形式 H_w¹ = Σ_j w̃_j²/Δ_j² 只差对数因子（H_w ≤ H_w¹ ≤ (1 + ln M) H_w）。下界的复杂度是 w_1²/Δ_2² + Σ_j w_j²/Δ_j²。两者都随覆盖率的平方缩放：**覆盖率平方因子不是证明技巧的产物，而是问题本身的难度**。当最优臂的覆盖率不大于其主要竞争者（w_1 ≲ w_j）时，上下界在常数与对数因子内一致；当最优臂覆盖很宽、而大量竞争者很窄时，上界中的 w̃_j = max(w_1, w_j) 比下界的 w_j 大，二者至多差一个与 M 有关的因子，是否能用"按覆盖率分层的减半"消除这个缺口，留作开放问题。

**含义**：同一个差距 Δ，覆盖率为 w 的候选，区分它所需的重放数随 w² 下降。这给出"先粗筛很多窄候选、再集中预算"的连续减半为什么比"先把宽候选评估完"的上界顺序好的理论原因：宽候选（w ≈ 1）是最难的臂，按上界顺序恰好先碰它们。

**有限总体的补充**：每个臂至多有 |F_j| 个不同的局，拉满之后只剩重放噪声。上面的下界在 E[N_j] ≤ |F_j| 时有意义；若 v w_j² log(1/(2.4δ)) / (4Δ_j²) > |F_j|，则任何算法都必须把该臂的局拉满并重复重放，此时问题退化为对固定 |F_j| 个局的重放噪声的估计。

## 20. 结构化搜索：用共享模型绕开定理 E 的下界（Lattice-Lin）

定理 E 的下界针对的是**无结构**实例：各候选的续跑值互不相关，所以每个候选都要自己被拉足 w_j²/Δ_j² 量级的次数，总量随候选数 K 线性增长。格里的候选并非无关：同一局在同一个分叉步上，不同谓词触发的是同一种效果，结局取决于分叉步的状态（哪些原子成立、记录结局），与是哪个谓词触发无关。把这一点写成模型：

**假设 L（线性结构）**：对效果 e、局 i、谓词 C（在局 i 中第一次触发于第 k_C(i) 步），一次重放的增益 D = Y′ − Y_i 满足 E[D] = φ(i, C, e)ᵀθ + b(i, C, e)，其中 φ 是 d 维特征（效果的独热编码 ×［常数、Y_i、第 k_C(i) 步成立的原子］），噪声 D − E[D] 是 σ-次高斯，|b| ≤ ε（模型误差）。实现里 d = 3 ×（2 + 33）= 105。

在假设 L 下，候选 (C, e) 的效果是 Δ_C = x_Cᵀθ + β_C，其中 x_C = (1/N) Σ_{i∈F_C} φ(i, C, e) = w_C · φ̄_C，φ̄_C 是 F_C 上特征的平均，|β_C| ≤ w_C ε。

**定理 F（维数代替候选数）**：设 Φ 是所有 (i, C, e) 的特征集合，λ* 是 Φ 上的 G-最优设计（Kiefer–Wolfowitz：max_{φ∈Φ} ‖φ‖²_{A(λ*)⁻¹} = d，A(λ) = Σ λ_φ φφᵀ）。按 λ* 做 n 次重放（四舍五入到整数，Soare 等 2014），用最小二乘得 θ̂。则以概率 ≥ 1 − δ，对所有 K 个候选同时有

    |x_Cᵀθ̂ − Δ_C| ≤ w_C · ( σ √(2 d log(2K/δ) / n) + (1 + √d) ε )。

于是只要 n ≥ 32σ² d log(2K/δ) · max_C (w̃_C/Δ_C)²，其中 Δ_C 为候选 C 与最优候选 1 的差距、w̃_C = max(w_C, w_1)，且模型误差满足 (1 + √d) ε w̃_C < Δ_C/4，按 x_Cᵀθ̂ 取最大即以概率 ≥ 1 − δ 返回最优候选（两者的估计误差各 < Δ_C/2：噪声项与偏差项各 ≤ Δ_C/4）。

证明：最小二乘 θ̂ − θ = A⁻¹ Σ φ_t (η_t + b_t)。噪声部分：x_Cᵀ A⁻¹ Σ φ_t η_t 是 σ‖x_C‖_{A⁻¹}-次高斯。因为 φ̄_C 是 Φ 中点的凸组合，而 ‖·‖²_{A⁻¹} 是凸函数，‖φ̄_C‖²_{A⁻¹} ≤ max_{φ∈Φ} ‖φ‖²_{A⁻¹} = d/n，故 ‖x_C‖²_{A⁻¹} ≤ w_C² d/n；对 K 个候选取并集即得第一项。偏差部分：|x_Cᵀ A⁻¹ Σ φ_t b_t| ≤ ε · Σ_t |x_Cᵀ A⁻¹ φ_t| ≤ ε √n · √(Σ_t (x_Cᵀ A⁻¹ φ_t)²) = ε √n ‖x_C‖_{A⁻¹} ≤ ε w_C √d（Cauchy–Schwarz；Lattimore 与 Szepesvári 2020，第 22 章的误设分析给出同阶），加上 |β_C| ≤ w_C ε，合并为 w_C ε (1 + √d)。∎

（误设下的 √d 放大是线性老虎机的已知现象：Lattimore、Szepesvári 与 Weisz 2020 证明它在最坏情况下不可避免。）

**与定理 E 对比**：无结构下界 Σ_j w_j²/Δ_j² 对 K 个候选求和；结构下的上界是 d · max_C w_C²/Δ_C²，只依赖维数 d 和 log K。Qwen2.5 B 半上 K ≈ 2200 个候选、d = 105，结构把需要的重放数的量级从 K 降到 d。定理 E 并不矛盾：它的困难实例让每个候选的续跑值独立变化，违反了假设 L。

**命题 G（认证与模型无关）**：无论假设 L 是否成立、模型误差 ε 多大，Lattice-Lin 返回的改动满足 P(Δ < τ) ≤ δ。理由：搜索只决定把哪 m 个候选送去认证；认证用新种子（rep 700+），在给定搜索结果的条件下与搜索独立，第 j 次尝试的单侧检验水平为 δ/m，并集界给出 δ（与定理 D 和 §9 相同）。模型错只会让送去认证的候选变差，即降低功效，不会产生假认证。这和预测驱动推断（Angelopoulos 等 2023）的分工一样：模型提供效率，独立样本提供有效性。

**实现与理论的差距（如实写）**：实现用 Thompson 采样选臂（预注册的协议），而定理 F 针对固定的 G-最优设计。Thompson 采样在线性最优臂识别上的保证弱于设计法；我们用它是因为它自然把预算集中到看起来好的区域。模型误差 ε 未知，离线预检中预测与实测的相关系数为 0.67–0.80，说明 ε 不小，所以定理 F 解释为什么结构有帮助，命题 G 保证即使模型不准结论也可靠。

## 21. SH-Lin：收缩为什么能防止好候选在前几轮被噪声淘汰

**观察（12 种子实验）**：标准连续减半输掉最优候选，几乎都发生在第一轮。那时每个候选只拉 t = 2 次，单次增益 x ∈ [−1, 1]，均值的噪声是 O(1/√2)，而候选之间的差距只有 0.05–0.09（乘以覆盖率后）。

**估计量**：候选 C 在本轮已拉 t 次，自身均值 x̄_C（每局尺度），模型预测 p_C = φ̄_Cᵀθ̂（每局尺度），收缩估计

    μ̃_C = λ x̄_C + (1 − λ) p_C，    λ = t / (t + κ)，    Δ̃_C = w_C μ̃_C。

（实现里 κ 再乘有限总体修正 1 − (t − 1)/|F_C|，拉满时 λ = 1。）记模型偏差 b_C = p_C − μ_C。

**命题 H（单轮比较）**：设单次增益在 [−1, 1] 内（Hoeffding 代理方差 1），模型在本轮视为固定（用上一轮及之前的拉臂拟合，与本轮新拉臂独立）。对最优候选 1 和任一候选 j，差距 Δ_1j = Δ_1 − Δ_j > 0，若

    (1 − λ)(w_1 |b_1| + w_j |b_j|) ≤ Δ_1j / 2，

则

    P(Δ̃_j ≥ Δ̃_1) ≤ exp( − t Δ_1j² / (8 λ² (w_1² + w_j²)) )。

不收缩（λ = 1，即标准 SH）时的同一界是 exp(−t Δ_1j² / (2(w_1² + w_j²)))。所以收缩把指数乘以 1/(4λ²) = (t + κ)²/(4t²)：t < κ 时 λ < 1/2，指数更大。例如 t = 2、κ = 4 时 λ = 1/3，指数放大 2.25 倍；t = 1 时放大 6.25 倍。轮数增加、t ≫ κ 后 λ → 1，退化为标准 SH。

证明：Δ̃_1 − Δ̃_j − Δ_1j = λ[w_1(x̄_1 − μ_1) − w_j(x̄_j − μ_j)] + (1 − λ)(w_1 b_1 − w_j b_j)。第二项的绝对值 ≤ Δ_1j/2（条件）。第一项是 t 个独立有界项之和除以 t 再乘 λ，代理方差 λ²(w_1² + w_j²)/t；事件 Δ̃_j ≥ Δ̃_1 要求它 ≤ −Δ_1j/2，由 Hoeffding 得界。∎

**推论 H1（固定预算）**：把命题 H 代入 Karnin 等（2013）的逐轮论证（定理 B 的证明），第 r 轮的指数乘以 1/(4λ_r²)，λ_r = t_r/(t_r + κ)。只要每一轮的模型偏差满足命题 H 的条件，SH-Lin 输掉最优候选的概率上界不大于标准 SH 的上界；在 t_r < κ 的前几轮严格更小。

**什么时候会变差（如实写）**：如果模型对最优候选严重低估（|b_1| 大），前几轮 λ 小，最优候选会被模型"压住"而淘汰，这时 SH-Lin 比 SH 差。命题 H 的条件就是在说"模型偏差要小于差距的一半"。实测中，开发集上 SH-Lin 在所有预算下都优于 SH（+1.1 到 +1.7 点），说明在 ALFWorld 上这个条件大体成立。无论哪种情况，认证仍然有效（命题 G）：模型错只会降低找到好改动的概率，不会产生假认证。

**实现与命题的差距**：实现里每轮淘汰前用包含本轮新拉臂在内的全部数据重拟合模型，所以 p_C 与本轮的 x̄_C 不独立；命题 H 假定模型只用之前各轮的数据（样本切分版本）。两者的差别是本轮新拉臂对 θ̂ 的影响，在候选很多、每个候选只占全部拉臂很小一部分时可以忽略，但严格的保证只对切分版本成立。

**与 κ 的关系**：κ 越大，前几轮越信模型（λ 越小），收益和风险都越大。开发集上固定 κ = 4 与矩估计的 κ 表现相当，说明结果对 κ 不敏感。

## 22. Lattice-Share：协调抽样 + 重放共享树（新算法）

**结构**：候选 C = (φ, e) 在局 i 上第一次触发于第 k_C(i) 步。称 (i, k_C(i), e) 为 C 在局 i 上的**格子**。Qwen2.5 B 半上，2232 个候选全评估需 54132 次重放，但只落在 6261 个格子里，平均每个格子 8.6 个候选（中位数 6，最多 69）。

**耦合重放（重放共享树）**：同一格子里，候选 C 已有一条重放 ρ（逐步记录：基础采样 r_s、它的属性、C 是否触发、重试采样及其提示、最终回复）。为候选 C' 生成重放时沿 ρ 走：
1. 第 s 步取 ρ 的基础采样 r_s（此时两条轨迹状态相同），用 C' 自己的谓词判断是否触发；
2. 若与 C 的判断相同且都不触发：最终回复就是 r_s；都触发：逐个沿用 ρ 的重试采样（要求提示词——含反馈文字——完全相同），用 C' 自己的停止规则；ρ 的重试不够或提示词不同，就从那里新采样；
3. 一旦 C' 的最终回复与 ρ 不同，或用到了任何新采样，此后整局都新跑。

**定理 I（共享重放无偏）**：按上述方式为 C' 生成的轨迹，其分布与独立地从 π^{C'} 重放（同一分叉点）完全相同。

证明：对步数归纳。设到第 s 步为止，构造出的前缀分布等于 π^{C'} 下的前缀分布，且（若仍在跟随）与 ρ 的前缀相同。第 s 步的基础采样 r_s 是在同一状态、同一提示下从基础策略抽的，所以对 C' 也是正确的条件分布（C 和 C' 在触发之前用的是同一个基础策略）。触发判断是 r_s 及状态的确定函数，C' 用自己的判断。若都触发，第 t 次重试的提示由状态和第 t − 1 次的回复决定；当提示相同时，ρ 的第 t 次重试采样是从同一条件分布抽的，ρ 中"是否存在第 t 次重试"只取决于 C 对第 t − 1 次回复的判断，与第 t 次采样的取值独立，所以"有就用、没有就新采"给出的仍是正确条件分布。新采样当然正确。于是第 s 步结束时的前缀分布仍等于 π^{C'} 下的分布。∎

推论：所有基于独立重放的结论（定理 1 的无偏性、认证定理）对共享重放照样成立；同一格子里不同候选的样本相关，但这只影响候选之间比较的方差（同种子耦合，通常使比较更准），不影响单个候选估计的无偏性。

**协调抽样**：所有候选共用局的同一个随机排列 π（由种子决定），候选 C 的第 t 次拉臂取 F_C 中按 π 排第 t 的局。

**命题 J（协调抽样无偏且共享最大）**：(a) 对每个 C，前 t 次拉到的局是 F_C 中均匀随机的大小为 t 的子集，所以无放回均值是无偏的，定理 B / 命题 H 的分析照样适用；(b) 若 F_{C'} ⊆ F_C（格中的细化），则 C' 前 t 次拉到的局全部也会被 C 拉到，只要 C 已拉到 F_C 中排序不晚于这些局的位置；嵌套候选的样本因此最大程度重合，同一格子的重放可以共享。

证明：(a) π 是均匀随机排列，它在 F_C 上的限制也是均匀随机排列，前 t 个即均匀随机 t 子集。(b) π 限制到 F_{C'} 的前 t 个元素都在 F_C 里，并且它们在 F_C 中的排名不超过它们在全体中的排名。∎（这与调查抽样的永久随机数协调、数据库草图中的 bottom-k 一致性抽样是同一个机制。）

**成本**：一次拉臂的成本 = 分歧之后的新调用数。格子里的第一次拉臂付全价；之后同一格子里的候选只为分歧后的部分付费，若整局都与某条已有重放一致则免费。全格评估的成本因此从 Σ_C |F_C| 次完整重放降到"每个格子一棵重放树的总边数"。上限是 8.6 倍（所有候选分叉后决策都一致时），实测见 share_eval。

**与老虎机文献的关系**：这是一种**代价随历史变化、带精确旁观测**的最优臂识别：拉臂 (C, i) 的成本取决于格子 (i, k_C(i), e) 里已有的重放；一次重放同时给出同格子里所有"决策一致"候选的精确样本（旁观测图在重放之后才揭晓）。已有的带旁观测的老虎机（Mannor 与 Shamir 2011 等）假设观测图事先已知、每次拉臂成本固定；组合纯探索（Chen 等 2014）假设基础臂独立。这里两者都不成立。

## 23. 反事实库迭代（Counterfactual Store Iteration, CSI）

**动机**：how-to 一次只找一个改动。修好最大的问题后，agent 的失败分布变了，下一个最有用的改动只能在"已打补丁的 agent"上找。直接做法是部署补丁后的 agent 重新收集轨迹，太贵。

**补丁**：P = C_1 ;; … ;; C_m，每一步按顺序作用：基础回复先过 C_1，其输出再过 C_2，依此类推（`engine.replay_patch`）。

**库与物化**：库 S 是 N 局轨迹，每局在任务 g_i 上由某个策略产生。给定补丁 P 下的库 S（即 S 的每局轨迹都是 π^P 在 g_i 上的样本）和新改动 C，令 k_i 为 C 在 S 第 i 局上第一次触发的步。物化 S' = S ⊕ C：受影响的局（k_i 存在）换成一条从 k_i 分叉、在补丁 P ;; C 下的重放（分叉步只对存储的回复施加 C，之后每一步的新采样都过整个补丁）；其余局保持不变。

**定理 K（库更新定理）**：若 S 的各局相互独立，且第 i 局服从 π^P(· | g_i)，则 S' 的各局相互独立，且第 i 局服从 π^{P;;C}(· | g_i)。

证明：固定第 i 局。π^P 与 π^{P;;C} 在 C 第一次触发之前的每一步都完全相同（C 不触发时 P;;C 的输出就是 P 的输出），所以记录的前缀（到 k_i − 1 为止）对两者是同一个分布的样本。第 k_i 步存储的回复是 π^P 在该步的输出，也就是 π^{P;;C} 在该步施加 C 之前的输出；对它施加 C 正是 π^{P;;C} 在该步的行为。此后重放从 π^{P;;C} 采样。由此第 i 局整条轨迹服从 π^{P;;C}（这就是定理 1 的耦合论证，作用在 π^P 的库上）。未受影响的局：C 从未触发，轨迹在 π^P 与 π^{P;;C} 下概率相同。各局的重放用各自独立的随机性，独立性保持。∎

**推论 K1（迭代认证）**：第 r 轮在 S_{r−1}（服从 π^{P_{r−1}}）上搜索、在新种子上认证 C_r（水平 δ_r）。由定理 K 和认证定理，P(Δ(P_r vs P_{r−1}) < τ_r) ≤ δ_r；并集界给出所有 R 轮的认证同时成立的概率 ≥ 1 − Σ δ_r，此时 P_R 相对原策略的提升 ≥ Σ_r (认证下界_r)。物化不额外花钱：认证本来就对每个受影响的局重放一次，那批重放就是 S_r。

**注意**：
1. S_r 中每局只有一条轨迹（与真部署一样），不是期望值，所以各轮之间没有偏差累积；但后一轮的搜索与认证都在同一个 S_r 上，和第 1 轮在原始日志上的情况相同（认证的总体是 S_r 的任务、以 S_r 的结局为基线）。
2. 补丁的语义是"顺序流水线"：C_r 的重采样不再被 C_1..C_{r−1} 复查。部署时用同样的语义（`ab.py` 从头跑整个补丁）。
3. 迭代收益可能递减：修掉最大的问题后，剩下的失败更分散。
