# GoWhy 的理论部分（论文方法章节底稿）

2026-10-08。记号和命题，配实测对照。证明写到能直接改写进论文的程度。

## 1. 模型

- **Agent 是"提示 → 回复"的随机策略**：第 k 步，harness 把任务、历史和当前观察拼成提示 p_k（AgentDebug 的 harness 是无状态的，每步一条完整提示），策略按温度 T 采样回复 r_k ~ π(· | p_k)，解析出动作 a_k，环境确定性地给出下一观察。所以一局游戏是一条马尔可夫链，状态就是提示，**下一步动作的分布只由当前提示决定**。
- **轨迹库**：N 局游戏 g_1..g_N，每局一条用基础策略 π 跑出的轨迹 τ_i 和结局 Y_i ∈ {0,1}。
- **改动 C = (谓词 φ, 效果 e, 作用域)**：在 φ(当前步属性, 即将采取的回复) 为真的步上，把 π 替换成 e 定义的新采样过程（拒绝重抽、反馈后重答、换模型、固定动作），作用域 FIRST 只在第一次触发时生效，ALL 每次触发都生效。改后策略记 π^C。
- **查询目标**：Δ(C) = (1/N) Σ_i ( E_{π^C}[Y | g_i] − E_π[Y | g_i] )，即"在这批游戏上部署 C 后，成功率变化多少"。

## 2. 分叉重放估计量

对第 i 局，令 k_i 为 τ_i 上第一个使 φ 为真的步（找不到则 a_i = 0，否则 a_i = 1）。从 τ_i 的前 k_i 步出发，在第 k_i 步用**记录里的那个回复**作为 π^C 的第一次采样，施加效果 e，然后按 π^C 继续到结束，独立重复 n 次，得 V̂_i（n 次的胜率）。

  D_i = a_i ( V̂_i − Y_i ),  Δ̂ = (1/N) Σ_i D_i,  SE = sd(D) / √N.

**命题 1（无偏）。** E[Δ̂] = Δ(C)。

证明要点：对固定游戏 g，把 π 和 π^C 耦合在同一组随机数上。在第一次触发之前，π^C 和 π 的每一步采样分布完全相同（触发条件不成立时 π^C 就是 π），所以前缀 τ_{<k} 在两种策略下同分布，"在第 k 步首次触发"的事件也同概率。在首次触发的那一步，π^C 的第一次采样就是 π 的采样，记录里的回复正是这样一个样本；之后按 π^C 继续，所以 V̂_i 在给定前缀下是 E_{π^C}[Y | τ_{≤k}] 的无偏估计。没触发的局（a_i = 0），整条轨迹在 π^C 下与在 π 下相同，结局不变，差为 0。对前缀分布取期望，E[a_i V̂_i + (1 − a_i) Y_i] = E_{π^C}[Y | g_i]，而 E[Y_i] = E_π[Y | g_i]。∎

推论：未受影响的局**不需要任何重放**，成本只花在受影响局的后缀上。

**注意（选择偏差）**：命题 1 要求 φ 和 C 与 τ_i 的结局无关地事先给定。若 C 是看着同一批 Y_i 挑出来的（挖掘、HOWTO 选最大），Δ̂ 有正偏差（赢家诅咒、回归均值）。我们的协议：在 A 半挖候选，在 B 半估计；对选中的 C 用与选拔不重叠的重放认证；最后在没见过的游戏上 A/B。实测：未认证的"决定性步"15 个里 12 个是假的；A/B 划分与重复运行的挑选共用同一个哈希时，效果虚高约 3 点（PLAN.md 第 9 步）。

## 3. 方差分解与最优重放次数

记 V_i = E_{π^C}[Y | τ_{i,≤k_i}]（给定前缀的真实续跑胜率）。

  Var(D_i) = Var( a_i (V_i − Y_i) ) + E[ a_i V_i (1 − V_i) ] / n  =:  A + B / n.

第一项 A 是"局与局之间"的部分（前缀和记录结局的随机性），不随 n 减小；第二项 B/n 是续跑本身的伯努利噪声。

**命题 2（每局一次最省）。** 设每次续跑的期望成本为 c（token 或调用数），总成本 C(n) = n c Σ_i a_i。则精度与成本的乘积

  SE² · C(n) ∝ (A + B/n) · n = A n + B

关于 n 单调递增，在 n = 1 取最小。更一般地，若只对受影响局的随机子集（概率 q）重放并用 1/q 加权（Horvitz–Thompson），乘积为 (M/q − Δ²) q = M − Δ² q，M = E[a (V̂ − Y)²]，关于 q 单调递减，在 q = 1 取最小。所以**最省的设计是：每个受影响的局恰好重放一次**。

这同时解释了 CV-index 的失败（README 中 T1 不通过）：只物化部分单元格再按 1/q 放大，正是 q < 1 的设计，方差按 1/q 放大，换什么价值模型都压不下来。

**实测对照**（PLAN.md G1）：用 n = 8 估出 A、B，预测 n = 1、2、4 的 SE。

| 模型 | A | B | 预测 SE（n = 1/2/4） | 实测 SE |
| --- | --- | --- | --- | --- |
| Qwen2.5-7B，影响 84% | 0.0563 | 0.0686 | 2.04 / 1.74 / 1.56 | 2.08 / 1.76 / 1.58 |
| Qwen3-8B，影响 22% | 0.0246 | 0.0151 | 1.15 / 1.03 / 0.97 | 1.16 / 1.07 / 0.98 |

## 4. 与重新部署比较

从头部署（A/B）的配对差 D_i^dep = Ȳ_i^{C} − Y_i，每局都要从头跑，且未受影响的局也贡献方差（两次独立运行结局不同）：

  Var(D^dep) ≈ Σ 每局两次独立运行之差的方差 ≈ 2 p (1 − p)（p 为基线成功率附近）。

而分叉重放对未受影响的局方差为 0、成本为 0，对受影响的局只付后缀成本。效率比（同等 SE 所需成本之比）

  [Var(D^dep) · c_full] / [ (A + B) · c_suffix · frac_affected ].

实测（达到 ±1 点所需 token）：Qwen3 4M 对 103M（约 26 倍），Qwen2.5 48M 对 103M（约 2 倍）。影响面越小、分叉越晚，优势越大；影响面接近全体且分叉很早时，优势降到约 2 倍，但不会比部署差（因为 A ≤ Var(D^dep) 成立当且仅当 ……待证，实测成立）。

## 5. 公共随机数（候选之间的比较）

给每次采样一个只依赖（游戏、重放编号、步、步内第几次采样）的种子，与改动无关。两个改动 C_1、C_2 在同一局同一重放编号下用同一串种子：在两者历史相同的步上，采样结果相同（vLLM 批内数值差异会偶尔打破，实测动作一致率 0.97，不固定种子时 0.81），历史分开后各自独立。于是 Cov(D_i(C_1), D_i(C_2)) > 0，差 Δ̂(C_1) − Δ̂(C_2) 的方差小于独立采样时，HOWTO 的排序更准。效果大小待 G2 实测。

只有同一族候选（同谓词、不同效果强度）在分叉后还有共同历史；不同谓词的候选分叉点不同，计算共享只有约 15%（G1 第 2 项不通过），所以公共随机数的收益在"比较更准"，不在"算得更少"。
